# OWASP ASVS v5.0 (Application Security Verification Standard) Reference Document

## Structure & Verification Levels:
* **Level 1 (L1):** Baseline technical security controls (input validation, authentication, session management) for all web applications.
* **Level 2 (L2):** Enhanced protection for sensitive business transactions and healthcare/financial data.
* **Level 3 (L3):** High-assurance security for critical infrastructure and financial/defense applications.

## Key Sections:
* **V1:** Architecture, Threat Modeling & Communications
* **V2:** Authentication Verification (Password Policy, MFA, Account Lockout)
* **V3:** Session Management Verification
* **V4:** Access Control Verification (RBAC & Enforcement)
* **V5:** Validation, Sanitization & Encoding (Injection Prevention)
* **V13:** API and Web Service Verification
